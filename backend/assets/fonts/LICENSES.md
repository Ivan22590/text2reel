# Шрифты: лицензии

Шрифты используются для субтитров (ASS, libass) и для карточек интро и аутро (Pillow). Все под **SIL Open Font License 1.1**: свободное использование, в том числе коммерческое; тексты лицензий лежат рядом (`OFL-*.txt`). Источник: репозиторий [google/fonts](https://github.com/google/fonts), каталог `ofl/`. Полная кириллица (А-я, Ёё, «», —, …, №) проверена по таблице cmap.

| `Lobster-Regular.ttf` | Lobster | Regular | `OFL-Lobster.txt` |
| `RussoOne-Regular.ttf` | Russo One | Regular | `OFL-RussoOne.txt` |

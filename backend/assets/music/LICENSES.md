## Как проверялась лицензия (2026-11-02)
- Для каждого файла через API Wikimedia Commons проверено поле `LicenseShortName` = `CC0`.
- Взяты только файлы **без** категории «License review needed» (проверка лицензии модератором Commons пройдена или файл опубликован автором самостоятельно). Треки Komiku с этой пометкой сознательно не использованы.
- Формат и размер каждого скачанного файла сверены с метаданными Commons; SHA-256 записан в `catalog.json`.

## Ограничения
- **Теги настроений выставлены по названиям, жанрам и описаниям альбомов, треки не прослушивались.** Если тег не соответствует звучанию, его можно поправить в `catalog.json` (поле `moods`).
- Бах и Альбинони: это композиции, чьи авторские права истекли, а CC0 относится к конкретным записям (Musopen). Для других записей тех же произведений лицензия может быть другой.
- CC0 не защищает от автоматических претензий Content ID на площадках (YouTube и др.): такие случаи возможны даже для свободной музыки. При публикации роликов проверяйте уведомления площадки.

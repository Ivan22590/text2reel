## Критерии оценки (100 баллов, зачёт от 60)

### 1. Техническое задание — 20 баллов
- [x] Все обязательные разделы: назначение, цели, ЦА, сценарии, требования, ограничения, риски, приёмка → [docs/TZ.md](TZ.md)
- [x] Чёткие цели и измеримые KPI → TZ §2 (K1–K8)
- [x] Границы: in scope и out of scope, ограничения, допущения → TZ §3
- [ ] Финальная вычитка, версия 1.0

### 2. Работоспособность MVP — 40 баллов
- [ ] Базовые сценарии US-1…US-4 проходят без ошибок
- [ ] 6 стилей × 3 формата рендерятся (матрица прогонов в [METRICS.md](METRICS.md))
- [ ] Нет критических ошибок: e2e-тест зелёный, CI зелёный
- [ ] Понятные сообщения об ошибках внешних API
- [ ] Демо-стенд стабилен на момент проверки

### 3. Документация и GitHub — 20 баллов
- [ ] Публичный репозиторий на GitHub
- [x] Подробный README с описанием и инструкцией по запуску → [README.md](../README.md)
- [ ] README актуален (статус, ссылка на демо, скриншоты)
- [x] `.env.example`, LICENSE, NOTICE
- [ ] Инструкция проверена на чистой машине

### 4. Визуальные материалы — 10 баллов
- [ ] 15+ скриншотов в [docs/screenshots/](screenshots/) (список в [DEMO_SCRIPT.md](DEMO_SCRIPT.md))
- [ ] Скринкаст работы или видеопрезентация

### 5. Библиотека промптов — 10 баллов
- [x] Отдельный документ → [docs/PROMPTS.md](PROMPTS.md)
- [ ] Все продуктовые промпты в финальных версиях
- [ ] Все промпты разработки записаны (часть B)

## Формат сдачи из description.md

| Артефакт | Где | Статус |
|---|---|---|
| Техническое задание | `docs/TZ.md` | 🔄 черновик |
| GitHub-репозиторий | ссылка | ⏳ |
| Скриншоты интерфейса (15+) | `docs/screenshots/` | ⏳ |
| 5+ примеров видео разных стилей | `examples/` + ссылки (YouTube unlisted / Диск) | ⏳ |
| Демо-доступ к платформе | URL + логин/пароль в README | ⏳ |
| Сравнение с конкурентами | `docs/COMPETITORS.md` | 🔄 черновик |
| Видеопрезентация 8–10 мин | ссылка, сценарий в `docs/DEMO_SCRIPT.md` | ⏳ |
| Библиотека промптов | `docs/PROMPTS.md` | 🔄 |

## Перед отправкой
- [ ] Все ссылки в README открываются из-под незалогиненного пользователя
- [ ] В репозитории нет ключей (`git log -p | grep -i key`) и `.env`
- [ ] Видео в `examples/` весят < 50 МБ каждое или вынесены во внешнее хранилище
- [ ] Демо-логин работает, лимит на число проектов включён

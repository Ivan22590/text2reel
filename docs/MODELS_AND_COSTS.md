# Модели и стоимость

> Идентификаторы и цены взяты из каталога https://proxyapi.ru/models/browse на 2026-11-03 (₽ за 1 млн токенов, с НДС 5 %). **Идентификаторы моделей ProxyAPI всегда с префиксом производителя** (`anthropic/claude-haiku-5-5`, `black-forest-labs/flux-3-image-klein`). Перед сдачей цены проверить заново.

## 1. Провайдер LLM: ProxyAPI

[ProxyAPI](https://proxyapi.ru) — российский шлюз к моделям OpenAI, Anthropic, Google, DeepSeek и open-source. Почему выбран:
- один ключ на все модели, оплата в рублях, работает без VPN;
- OpenAI-совместимый API, поэтому подходит стандартный SDK `openai` и модель можно сменить без правок кода;
- есть и генерация изображений: используется как основной провайдер картинок (раздел 3).

**Подключение:**
```python
from openai import OpenAI
client = OpenAI(api_key=settings.PROXYAPI_KEY, base_url=settings.PROXYAPI_BASE_URL)  # https://api.proxyapi.ru/v1
resp = client.chat.completions.create(model=settings.LLM_MODEL, messages=[...], response_format={"type": "json_object"})
```
Авторизация: заголовок `Authorization: Bearer <PROXYAPI_KEY>`.

**Идентификаторы** (из каталога, с префиксами): основная `anthropic/claude-haiku-5-5`, запасная `deepseek/deepseek-v4.1-flash`; обе прописаны в `.env.example` и `config.py` и есть в таблице цен `backend/app/services/llm/pricing.py`. Тест `test_env_example.py` следит, чтобы значения не разошлись и всегда содержали префикс. Проверить ключ и модели на сервере (копейки):
```bash
python -m app.cli llm-models --filter haiku     # убедиться, что id есть у вашего ключа
python -m app.cli smoke-llm                     # запрос к обеим моделям: ответ, токены, ₽, время
```

### Расчёт стоимости LLM на ролик
Ролик 60 с ≈ 150 слов ≈ 10 сцен.
- Ввод: system prompt около 1 200 токенов + сценарий около 400 ≈ **2k токенов**.
- Вывод: 10 сцен × около 250 токенов + style bible ≈ **3k токенов**.

| Модель | Ввод | Вывод | Итого |
|---|---|---|---|
| Claude Haiku 5.5 | 2k × 30/1M = 0,06 ₽ | 3k × 150/1M = 0,45 ₽ | **≈ 0,5 ₽** |
| DeepSeek V4.1 Flash | 0,05 ₽ | 0,30 ₽ | **≈ 0,35 ₽** |

Перегенерация одной сцены стоит около 0,05 ₽. На всю разработку и демо (около 300 вызовов) уйдёт **100–200 ₽**.

### Как экономим
- Короткий system prompt, без лишних примеров (один компактный few-shot).
- Кэш ответа по `sha256(script + style + model + prompt_version)`.
- `max_tokens` рассчитывается от длины сценария.
- При правке сцены перегенерируется только эта сцена.

## 3. Изображения

**Решение (2026-11-02, уточнено 2026-11-03): основной провайдер — ProxyAPI** (`IMAGE_PROVIDER=proxyapi`), Fal.ai остаётся запасным (`IMAGE_PROVIDER=fal`). Причины: один ключ и оплата в рублях, как для LLM; про доступность Fal.ai из РФ и оплату российскими картами в официальных источниках ничего нет (страница цен не называет способов оплаты и ограничений по странам, [обзор](https://aireiter.com/ru/blog/fal-ai-review-2026) советует регистрироваться с иностранного IP), поэтому рассчитывать на него без зарубежной карты нельзя.

### ProxyAPI Images API
По [документации](https://proxyapi.ru/docs/image-generation): `POST /v1/images/generations` в формате OpenAI, JSON с `model`, `prompt` и необязательными `size`, `quality`, `n`; картинка приходит в `data[0].b64_json` (ссылки нет, ProxyAPI результат не хранит); генерация медленнее текста, поэтому таймаут `IMAGE_TIMEOUT_SEC=120`. Не каждая модель принимает каждый параметр, неподдерживаемый даёт 400. `seed` и негативный промпт в документации не описаны.

Адаптер (`app/services/images/proxyapi.py`) под это устроен так:
- **Размер.** Размеры из `PROXYAPI_IMAGE_SIZES` пробуются по очереди, ближайший по пропорциям первым (по умолчанию 768×1344 для 9:16, 1344×768 для 16:9, затем 1024×1024, 1024×1536, 1536×1024); лишнее обрезается при кадрировании. Отвергнутый размер выбрасывается, затем пробуется 1024×1024 (единственный размер из документации), и в конце запрос идёт вообще без `size`. Отказы запоминаются на время задачи.
- **Параметры.** Отправляются только `model`, `prompt`, `n`, `size` и `quality` (только если задан, он нужен моделям OpenAI). `seed` включается флагом `PROXYAPI_IMAGE_SEND_SEED` через `extra_body`. Негативный промпт по умолчанию не отправляется (`PROXYAPI_IMAGE_NEGATIVE=append` дописывает его в промпт). Если модель не знает `quality`, адаптер перестаёт его слать.
- **Единый стиль без seed.** Держится на описании персонажей и стиля в каждом промпте (`style_bible`, префикс и суффикс стиля), как и раньше; общий seed есть только у Fal.
- **Стоимость.** Цены в каталоге указаны за миллион токенов, а токенов на картинку не написано. Адаптер берёт число токенов из `usage` ответа и умножает на цену модели из таблицы (или на `PROXYAPI_IMAGE_PRICE_IN_RUB` и `..._OUT_RUB`, если заданы: для моделей, которых нет в таблице); если `usage` нет, берёт фиксированную `PROXYAPI_IMAGE_COST_RUB`; если не задано ничего, стоимость 0 и в лог пишется предупреждение.

### Что не известно и как узнать (на VPS, около 1–3 ₽)
В каталоге и на странице модели (у Klein в примере только `model` и `prompt`) **нет допустимых размеров, поддержки `quality`, `seed` и негативного промпта, а также числа токенов на картинку**. Поэтому адаптер подбирает размер на ощупь, а цену берёт из токенов в ответе. Один тестовый запрос показывает всё сразу: какой размер принят, что получено, время, токены и стоимость:
```bash
python -m app.cli image-models                       # модели вашего ключа с ценами
python -m app.cli smoke-image                        # модель из .env (по умолчанию Klein)
python -m app.cli smoke-image --model <id из списка> # сравнить с другой моделью
```
Затем прогнать 10 кадров одного сценария (`python -m app.cli images sb.json --out-dir out/<модель>`) и сравнить стоимость и то, насколько кадры похожи друг на друга (общего seed у ProxyAPI нет).

### Fal.ai (запасной вариант)
FLUX.1 schnell, [$0,003 за мегапиксель](https://fal.ai/pricing), предоплаченные кредиты, есть `seed` (общий для всех кадров проекта, поэтому стиль держится лучше). Генерируем около 1 МП (9:16 → 768×1344, 16:9 → 1344×768, 1:1 → 1024×1024) и масштабируем до 1080p: ≈ 0,3 ₽ за кадр, ≈ 3 ₽ за 10 кадров при курсе 100 ₽/$. Параметры учёта: `FAL_COST_USD_PER_MP`, `USD_RUB`. Нужен ключ Fal (дашборд, раздел Keys) и зарубежный способ оплаты.

Кэш не даёт платить повторно за тот же кадр (ключ: провайдер, модель, промпт, размер, seed).

## 4. Позиционирование и выводы

**Сильные стороны Text2Reel:**
1. Уникальные AI-иллюстрации в едином стиле вместо стоковых видео. Ролики выглядят как авторская история, а не нарезка стоков.
2. Себестоимость в рублях на порядок ниже подписки, оплата через ProxyAPI без зарубежных карт.
3. Открытый код и self-hosted: данные остаются у владельца, можно менять провайдеров.
4. Хорошая поддержка русского: бесплатный нейро-TTS и субтитры по словам.

**Слабые стороны (честно):**
1. Нет видеогенерации (только анимация статичных кадров) и аватаров.
2. Нет полноценного редактора таймлайна.
3. Качество и скорость зависят от внешних API.
4. Один сервер без GPU ограничивает параллельность.

### Отличие от MoneyPrinterTurbo
От MoneyPrinterTurbo мы берём только «инфраструктурные» модули: озвучку с таймингами слов, сборку субтитров и микширование аудио. Продукт отличается по сути:

| | MoneyPrinterTurbo | Text2Reel |
|---|---|---|
| Вход | Тема или ключевое слово, сценарий пишет LLM | Готовый сценарий пользователя, LLM только делит его на сцены и пишет визуальные описания |
| Видеоряд | Стоковые видео (Pexels, Pixabay), найденные по ключевым словам | Уникальная AI-иллюстрация на каждую сцену + Ken Burns и переходы |
| Единый стиль | Нет: стоки разнородны | Style bible, общий seed, 6 пресетов стилей |
| Интерфейс | Форма на Streamlit | React: редактор сцен, перегенерация сцены, таймлайн, прогресс по SSE |
| Шаблоны и брендинг | Нет | JSON-шаблоны площадок, логотип, цвета, интро и аутро |
| Инфраструктура | Последовательная обработка | Очереди Celery `ai` и `render`, кэш, учёт стоимости |
| Доступ к LLM | Зарубежные API | ProxyAPI: оплата в рублях, работает без VPN |

**Ниша:** авторы коротких историй и объясняющих роликов на русском, которым нужен уникальный иллюстрированный визуал при минимальном бюджете.

## Этап 1. Разбивка сценария на сцены
- [ ] LLM-клиент ProxyAPI (`services/llm/client.py`): основная и запасная модель, повторы, учёт токенов
- [ ] Smoke-тест ProxyAPI
- [ ] Промпт `scene_split` и JSON-схема ответа
- [ ] Генерация `style_bible`
- [ ] Валидация (Pydantic), повторы, кэш по hash сценария
- [ ] Unit-тесты парсера

**Готово, когда** сценарий из 8 предложений даёт валидный JSON сцен за ≤ 15 с.

## Этап 2. Генерация изображений
- [ ] Адаптер провайдера картинок (`fal` / `proxyapi`)
- [ ] Пробный прогон обоих провайдеров, выбор основного (результат записать в MODELS_AND_COSTS)
- [ ] Пресеты 6 стилей, seed, negative prompt
- [ ] Параллельная генерация и кэш
- [ ] Кадрирование под 9:16, 16:9, 1:1 (cover / blur-fill)

**Готово, когда** 10 сцен в одном стиле генерируются за ≤ 60 с и выглядят консистентно.

## Этап 3. Синтез речи
- [ ] Адаптер Edge TTS (адаптация из MoneyPrinterTurbo, MIT)

- [ ] Выбор голоса (2 RU + 2 EN минимум)

**Готово, когда** рассинхрон субтитров ≤ 150 мс.
